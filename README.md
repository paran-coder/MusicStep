# MusicStep-v1.5.0

이 폴더 안 파일을 GitHub 저장소 최상위에 업로드합니다. 기존 v1.4.2 업로드본과 같은 평면 구조입니다. npm ci 후 npm run dev / npm test / npm run build를 실행합니다. Node.js 22.12 이상.

청록 위 손잡이·파형 클릭은 재생 이동, 노란 아래 손잡이는 자막 시작 조정입니다. 중복 슬라이더 제거, Space 재생/일시정지와 방향키 정밀 탐색을 추가했습니다. 기본 플레이어·자막 숫자·검수 저장을 유지합니다. 직접 재생 이동 시 구간 반복을 종료합니다.

Vercel: Vite / npm run build / dist. 음악·SRT는 브라우저 로컬 처리합니다. sample·개인 진단·node_modules는 포함하지 않습니다. test:sample은 별도 로컬 샘플 두 곡이 있을 때만 사용합니다.

개발 원본 검증: 단위 41, 브라우저 12, 커서 9, 재생 조작 16, 두 실제 샘플과 빌드 통과. 실제 서비스 재배포는 수행하지 않았습니다.
