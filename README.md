## v1.4.0: 듣고 한 번 눌러 연결하기

첫 가사 끝과 다음 가사 시작이 잘못된 곡은 숫자를 따로 입력할 필요가 없습니다.
1. **① 첫 가사부터 듣기**를 누릅니다. 짧은 구간 반복 없이 이어서 재생합니다.
2. 화면에 인용된 두 번째 가사가 시작되는 순간 **② 지금 두 번째 가사 시작 · 저장**을 누릅니다.

현재 재생 위치로 첫 가사 표시 끝과 두 번째 가사 표시 시작을 함께 맞추고 검수 완료로 저장합니다. 다시 듣고 바꿀 수도 있습니다. 숫자 입력은 ‘세부 조정’에 접혀 있습니다. 세 번째 이후 자막과 원본 파일은 유지합니다. 정상 곡은 기존대로 자동 완료되어 별도 클릭 없이 내보낼 수 있습니다.

검증: 기본 테스트 35/35, 브라우저 회귀 검사 12/12 통과. 실제 샘플 두 곡에서 검수 필요/자동 완료 구분, 연속 재생, 한 번 클릭으로 두 시간 저장, SRT 내보내기, 1024/768/390px 가로 넘침 없음, 외부 요청·업로드 0건을 확인했습니다. 테스트의 17초는 클릭 동작 검증값이며 실제 두 번째 가사의 정답을 의미하지 않습니다. 실제 GitHub/Vercel 배포는 미검증입니다.


작성·갱신: 2026-10-29

음악과 SRT를 브라우저에서 일괄 분석해 첫 가사 표시 시작을 맞추고, 통합/개별 음악과 자막을 내보내는 정적 웹앱입니다.

## 기본 사용

1. 음악과 SRT를 함께 불러옵니다. 같은 파일명은 자동 연결하고 다른 이름은 직접 연결합니다.
2. 전체 분석을 누릅니다. 기본은 약 9.56MB 노래 보컬 유무 감지 모델입니다.
3. 기준을 통과한 곡은 첫 가사 표시 시작을 자동 수정하고 자동 완료됩니다. 추가 확인 버튼을 누르지 않아도 됩니다.
4. 확인할 곡만 보기를 켜고, 검수 필요 곡의 노란 안내를 확인합니다.
5. 표시 시간을 조절한 뒤 확인한 시간 저장을 누르면 검수 완료됩니다.
6. 자동 완료와 검수 완료 곡을 함께 내보냅니다.

## 표시 시간은 음악 길이가 아닙니다

첫 가사 표시 시작/끝은 자막이 화면에 나타나고 사라지는 시각입니다. 예를 들어 목소리가 11.47초에 시작하는데 원본 첫 가사가 4.55초에 사라지도록 되어 있으면 시작만 바꿀 수 없습니다. 화면은 이유를 문장으로 설명하고 첫 가사 표시 끝과 두 번째 가사 표시 시작을 확인하도록 안내합니다. 종료 시각을 임의로 추측해 늘리지 않습니다.

## 자동 완료 기준

빠른 감지의 지속 후보 점수 기준, 첫 가사 및 다음 자막의 시간 순서, 음악 길이를 확인합니다. 현재 빠른 후보 점수 0.7 이상을 사용합니다. 점수는 정답 확률이 아닙니다. 후보 없음, 기준 미달, 표시 시간 충돌, 저장 전 수동 조정은 검수 필요로 남깁니다. 정밀 분리의 에너지 값은 이 분류 점수와 다르므로 정밀 모드는 사용자 확인을 거칩니다.

## 개인정보·내보내기

음악, 자막, 파일명, 파형, 분석 결과를 서버로 전송하지 않습니다. 앱·모델·WASM을 같은 사이트에서 다운로드하며 일반 접속 정보는 호스트에서 처리될 수 있습니다. 외부 분석 API/CDN/추적 SDK는 없습니다. sample, 로컬 진단 결과, 변환 환경·캐시·node_modules는 배포 ZIP에서 제외합니다.

통합 WAV+SRT ZIP, 개별 원본 음악+수정 SRT ZIP, 개별 수정 SRT ZIP, 통합 WAV 또는 SRT를 지원합니다. 통합 음악은 44.1kHz/16bit/stereo WAV이며 크로스페이드·MP3 출력은 없습니다. 각 곡 디코딩 메모리는 필요하며 Blob 저장은 512MB, RIFF WAV는 4GB 상한을 둡니다. 지원 브라우저의 디스크 직접 쓰기는 별도 저장 권한에 따릅니다.

작업 JSON v2에 적용한 시간과 SRT를 저장하고 v1도 읽습니다. 음악은 포함하지 않으며 복원 시 파일을 다시 선택하고 재분석 또는 직접 확인합니다.
