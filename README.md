# MusicStep-v1.6.0

폴더 안 파일을 저장소 최상위에 업로드합니다. Node.js 22.12 이상, npm ci 후 npm run dev / npm test / npm run build. Vercel: Vite / npm run build / dist.

상단 사용법 링크에서 8개 사용 안내와 목차를 확인합니다. #usage 경로에서 편집기로 돌아가도 불러온 음악·수정 시간·선택곡·검수 상태·재생 위치는 유지됩니다. 사용법 진입 시 음악은 일시정지합니다. 새로고침·탭 종료 전에는 작업 저장을 사용하세요. JSON은 음악을 포함하지 않습니다.

사용법 검사는 npm run test:usage입니다. 로컬 개발 원본과 빌드 모두 12개 통과. 단위 41·기존 브라우저 12·재생 조작 16·커서 9·두 실제 샘플 검사와 빌드 통과. 실제 서비스 배포는 수행하지 않았습니다. test:sample은 별도 샘플 파일이 있을 때만 사용합니다.
