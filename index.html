    첫 가사부터, 차근차근 맞추기

    음악과 SRT를 불러오고, 첫 목소리를 찾은 뒤 필요한 곡만 확인하세요. 청록색은 듣는 위치, 노란색은 자막이 나타나는 위치입니다.

    사용법과 편집기를 오가는 동안 불러온 파일과 편집 상태는 유지됩니다. 음악은 잠시 멈춥니다. 페이지 새로고침·탭 종료 전에는 ‘작업 저장’을 사용하세요.

    파일 불러오기분석·검수파형 조작단축키가사 경계내보내기저장·복원개인정보

    1. 음악과 SRT 불러오기

    1. 편집기의 음악·SRT 불러오기를 누르거나 파일을 끌어 놓습니다.
    2. 음악과 SRT의 확장자를 제외한 이름이 같으면 자동 연결합니다. 예: 노래.mp3와 노래.srt.
    3. 이름이 다르거나 중복되면 파일 연결 확인에서 대응하는 자막을 선택해 추가합니다.
    4. 왼쪽 목록에서 곡을 선택합니다. ↑·↓로 내보낼 순서를 바꾸고, 곡 사이 간격을 정할 수 있습니다.

    불러온 원본 파일 자체는 변경하지 않습니다.

    2. 분석하고 필요한 곡만 검수하기

    1. 처음에는 빠른 보컬 감지와 앞 30초를 사용해 전체 분석을 누릅니다. 후보가 없으면 분석 범위를 확장하거나 정밀 보컬 분리를 선택할 수 있습니다.
    2. 자동 완료는 감지 기준과 자막 시간 순서를 통과해 적용된 곡입니다. 추가 저장 없이 내보낼 수 있습니다.
    3. 검수 필요는 직접 듣고 시간을 확인할 곡입니다. ‘확인할 곡만 보기’ 또는 ‘확인할 곡으로’를 사용하세요.
    4. 저장 전은 직접 바꾼 시간이 아직 확정되지 않은 상태입니다. 듣고 확인한 뒤 ‘확인한 시간 저장’을 누릅니다.

    AI 후보는 정답 보장이 아닙니다. 악기·허밍·부드러운 보컬에 따라 틀릴 수 있습니다. 정밀 분석은 더 느리며 사용자 확인을 거칩니다.

    3. 파형에서 듣는 위치와 자막 시작 나누기

    • 청록 재생선·위 손잡이: 끌어서 듣는 위치를 옮깁니다. 파형 빈 곳을 클릭해도 이동합니다. 자막 시간은 바뀌지 않습니다.
    • 노란 선·아래 손잡이: 끌어서 첫 가사 표시 시작을 바꿉니다. 음악의 재생 위치는 바뀌지 않습니다.
    • 두 선이 겹치면 위는 재생, 아래는 자막 손잡이를 잡으세요.
    • 정확한 자막 시간은 ‘첫 가사 표시 시작 (초)’ 입력 또는 ± 버튼으로 조정합니다. ± 버튼은 0.1초 단위입니다.
    • 파형 범위는 앞 30초·앞 60초·곡 전체 중 선택합니다. 플레이어는 곡 전체이므로 표시 범위 밖에서는 청록 선이 보이지 않을 수 있습니다.

    ‘시작 전후 듣기’는 자막 시작 전후를 재생합니다. 반복을 켜면 그 구간을 반복하고, 직접 재생 위치를 옮기면 구간 반복에서 벗어납니다.

    4. 키보드로 빠르게 듣기

    • Space: 편집기의 일반 화면이나 파형에서 재생·일시정지합니다.
    • 파형을 클릭하거나 Tab으로 포커스를 옮긴 뒤 ←·→: 1초씩 이동합니다.
    • Shift + 방향키: 0.1초씩 이동합니다.
    • 파형에서 Home·End: 곡 처음·끝으로 이동합니다.

    숫자 입력창·버튼·선택 상자·기본 음악 플레이어에서는 해당 컨트롤의 원래 키보드 동작을 유지합니다. 사용법을 읽는 동안 Space는 숨겨진 음악을 재생하지 않습니다.

    5. 첫 가사 끝과 다음 가사 시작이 맞지 않을 때

    첫 목소리보다 자막 표시 끝이 빠르면 시작만 바꿀 수 없습니다. 아래 안내에 따라 두 가사의 경계를 맞추세요.

    1. ① 첫 가사부터 듣기를 누릅니다. 짧은 구간 반복 없이 이어서 듣습니다.
    2. 화면에 인용된 두 번째 가사가 시작되는 순간 ② 지금 두 번째 가사 시작 · 저장을 누릅니다.
    3. 그 위치로 첫 가사 표시 끝과 두 번째 가사 표시 시작을 함께 맞추고 검수 완료로 저장합니다.

    다시 듣고 바꿀 수 있습니다. 필요하면 ‘세부 조정’에서 숫자로 경계를 맞춥니다. 표시 끝은 음악 길이가 아니라 자막이 사라지는 시각입니다. 세 번째 이후 자막은 그대로 유지합니다.

    6. 순서를 확인하고 내보내기

    자동 완료와 검수 완료 곡을 내보냅니다. 미완료 곡이 있으면 먼저 검수하고 저장하세요.

    • 통합 음악 + 통합 SRT: 플레이리스트 순서와 곡 사이 간격을 반영한 WAV·SRT ZIP.
    • 개별 음악 + 자막: 원본 음악과 수정 SRT를 묶은 ZIP.
    • 개별 수정 SRT ZIP, 통합 WAV 또는 통합 SRT만 저장할 수도 있습니다.

    통합 음악은 44.1kHz·16bit·스테레오 WAV입니다. MP3 변환과 크로스페이드는 지원하지 않습니다. 큰 작업은 브라우저 메모리·저장 방식에 따라 나눠 내보내야 할 수 있습니다.

    7. 작업 저장과 복원

    1. 편집기 상단 작업 저장으로 현재 시간 설정과 자막을 JSON 파일로 내려받습니다.
    2. 다시 시작할 때 작업 열기에서 JSON을 선택합니다.
    3. 같은 음악 파일을 다시 불러와 연결하고 재분석하거나 직접 확인해 마무리합니다.

    작업 JSON에는 음악 파일이 포함되지 않습니다. 새로고침하거나 탭을 닫으면 브라우저 메모리의 파일은 사라집니다. 원본 음악과 작업 JSON을 함께 보관하세요.

    8. 파일과 개인정보 처리

    음악·SRT·파일명·가사·파형·분석 결과를 분석 서버로 업로드하지 않습니다. 처리와 분석은 사용자의 브라우저에서 수행합니다. 앱·모델·실행 파일은 같은 사이트에서 다운로드하며, 일반 접속 정보는 호스팅 서비스에서 처리될 수 있습니다.

    인터넷 연결 없이 모든 최초 실행이 가능한 것은 아닙니다. 모델의 초기 다운로드와 기기 성능에 따라 준비·분석 시간이 달라집니다. Chrome·Edge 사용을 권장하며, 다른 브라우저의 실제 동작은 별도 확인이 필요합니다.
